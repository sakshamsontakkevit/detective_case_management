# Problem Statement

## Problem
Teachers and students often keep marks in notebooks or loose sheets. Working out
averages, grades, GPA and class rankings by hand is slow and easy to get wrong.

## Scope
A command-line program that stores student marks in a local JSON file, calculates
grades and GPA, and prints report cards and class summaries. It does not use a
database, a GUI or any external library.

## Target Users
- Teachers or class representatives who track marks for a small class
- Students who want to check their own average, grade and GPA

## High-Level Features
1. **Student management** - add, search, view and delete students (CRUD)
2. **Marks and grading** - enter marks per subject, get letter grades, GPA and pass/fail
3. **Reports** - ranked student list, individual report card, class summary with subject averages
