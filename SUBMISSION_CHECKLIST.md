# Submission Checklist

1. Extract the ZIP.
2. Open the project folder in VS Code.
3. Open Terminal.
4. Run:
   `python detective_case_management.py`
5. Select `7. Load Demo Data` to demonstrate the application.
6. Test creating a case, investigator, suspect, witness and evidence.
7. Push the complete folder to a public GitHub repository if required.

The project uses only Python's standard library.
